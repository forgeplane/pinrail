# Changelog

This plugin is released with the Pinrail app, which carries it among its
official plugins. Each version names the release of the app that first
carries it.

## [1.2.0] - Pinrail 0.4.1

### Changed

- An item's note looks like the change map's field: one box with the
  text and the microphone. Once the text wraps, the microphone moves to
  a row under it, with the key that starts a new line.

### Fixed

- A long note grows to show all its text, rather than being cut off at
  its first line.

## [1.1.0] - Pinrail 0.3.0

### Added

- An item's note can be dictated in the macOS app, from a microphone in
  the note's corner.

### Changed

- The view fits a narrow frame, such as the inbox's side panel. Below
  760 pixels the list of items opens as a drawer over the review, and
  below 520 pixels the header's buttons show only their icons.
- An item's meta chips sit on a row of their own under its title.

## [1.0.0] - Pinrail 0.1.0

The first version. It shows items grouped under headings, each accepted
or rejected with an optional note, and the items left without a verdict
reported as undecided.
